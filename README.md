# Movie Review Website

## Project Description

My project is a movie review website where users can discover movies and read reviews.

### Features
- Display a list of movies.
- Show movie descriptions.
- Rate movies using a star rating system.
- Read movie reviews.

**Goal:** Create a simple and user-friendly movie website using Node.js and Express.

*This is my first Node.js project.*
